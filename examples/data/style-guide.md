# Style guide

Status: an example (gate 2)

REFERENCE ANALYSIS
none provided; the style below is the template's.
Palette: near-black ground #0d0d10, warm white type #f4f1ea, grey #8d8a84
for what's secondary, Omarchy yellow #ffd60a for the one thing to look at.
Typography: Adwaita Sans for words, bold for headlines; Liberation Mono for
commands and gates.
Composition: headline top left in the wide frame, top in the tall ones; one
object under it.
Pacing: a meaningful change every 3 seconds, one per beat.
Motion: headlines spring in word by word and hold; panels settle; the
camera eases, slowly enough to stay oriented.
Texture: none.

FONTS
Headlines and captions: Adwaita Sans, assets/AdwaitaSans-Regular.ttf.
Commands and lists: Liberation Mono, assets/LiberationMono-Regular.ttf.

MOTION RULES
Micro UI: quick, minimal overshoot
Panels: controlled settle
Camera: smooth, almost invisible
Headlines: strong entrance, stable hold

TOKENS
color background #0d0d10
color ink #f4f1ea
color dim #8d8a84
color accent #ffd60a
color card #17171c
color line #2c2c33

font code Liberation Mono
